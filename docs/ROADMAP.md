# 路线图

## v0.1（当前）

- [x] 云端 ASR + LLM 整理 + 写入光标（macOS / Windows / Linux）
- [x] 悬浮胶囊、全局热键、Esc 取消
- [x] 按住说话（松开结束）与按一下开始两种触发，新装默认按住，老配置保持原行为
- [x] 词典（反向映射 + 术语表）、历史、统计
- [x] 服务商配置与连通性测试
- [x] 四种整理方式、翻译输出、光标上下文
- [x] 移动端应用壳（同一 UI）
- [x] 桌面构建产物可运行（macOS `.app` 14.5 MB）

## v0.2 体验补齐（进行中）

- [x] 静音自动结束 / 无人声放弃
- [x] 空话与幻觉过滤、全大写英文还原、输出清洗
- [x] 词典改写整词 + 已写对不重替换
- [x] 历史手改 + 学词
- [x] 自定义整理要求
- [x] 近 14 天活跃条 / 语速 / 连续天数
- [x] 改写选区（第二快捷键，原地替换）
- [x] 快捷键录制控件 / 提示音 / 诊断包
- [x] 长录音护栏（48 kbps、10 分钟、20 MB）
- [x] 片段：说的短句替换成整段（润色后展开，最长优先）
- [x] 失败重试：音频留在内存，换网络后一键重跑
- [x] 本机 ASR 服务探测：`GET /models` 列出可选模型
- [x] 风格包：内置四种表达方式 + 自建 + 导入/导出 JSON + 热键轮换
- [x] 风格包可发现性：首页 chip、设置页当前来源、保存当前设置、界面语言跟随
- [x] 导入顺序 / 去重 / 剪贴板错误翻译；共享弹窗焦点锁与删除确认
- [x] 破坏性操作统一确认（清空历史 / 删除单条 / 恢复默认），请求中不可关闭
- [x] 风格包表单未保存修改提醒；风格页加载骨架
- [x] 风格包轮换范围与顺序：勾选进轮换、至少保留一个、自建包上移/下移
- [x] 界面收紧：桌面单行导航、移动端标签栏，首页去掉 eyebrow 与卡片套卡片
- [x] 服务商测试接真实请求：用屏幕草稿、返回模型数、失败标红；浏览器预览不再假成功

- [x] 菜单栏常驻图标（开始 / 打开 / 历史 / 设置 / 退出）
- [ ] 流式插入（逐字写光标，失败回退一次性粘贴）
- [ ] 选区问答 / 改写（`polish_text` 已就绪，缺选区读取）
- [ ] 光标上下文读取：macOS `AXUIElement`、Windows `TextPattern2`、Linux `AT-SPI`
- [ ] 词典“手改学词”：粘贴后观察编辑，候选词需确认才入库
- [x] 首次引导（欢迎 → 识别 → 整理 → 快捷键与试一句，可跳过；替代首页 checklist）
- [x] 单实例：第二次启动把已有窗口带到前台
- [x] 开机自启：登录后以 `--hidden` 静默进菜单栏
- [x] 系统钥匙串存 key（`keyring`），`settings.json` 只留引用；不可用时退回 0600 文件并提示

## v0.3 本机与移动

- [ ] 本机 ASR：sherpa-onnx（SenseVoice / Qwen3-ASR）+ 模型下载器（断点续传、SHA-256）
- [ ] Android 输入法壳（语音 + 剪贴板 + 英文面板）
- [ ] iOS 键盘扩展（只做插入，录音交给主应用）

## v0.4 生态

- [ ] BINRC Desk（`api.binrc.com/ai/v1`）：模型网关 + 模型目录 + ASR / 整理端点；客户端预设已接入
- [ ] “粘贴上一条”
- [ ] 自动更新与双频道（stable / beta）
- [ ] `bench/`：CER、端到端时延、真实口述样本回归

## 明确不做

- 不做账号、不做云端同步（先把本机做扎实）
- 不做“替你回答问题”的助手：Sona 只把话变成文字
- 不在 v0.x 引入社区市场后端
